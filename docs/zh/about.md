# 关于我

我是 **XX 大学 25 级人工智能专业本科生**。这个网站是我的公开数字花园：一部分用来记录学习和项目，一部分用来留下生活里的观察，还有一部分交给碧影，让访客可以用对话的方式认识我。

## 我的工作方式

我喜欢先把一个想法做出来，再在真实使用中发现问题。对我来说，代码不是只用来完成作业或通过测试的东西，它也可以是一种表达方式：把模糊的兴趣变成页面、工具、机器人、可交互系统，最后变成别人能体验到的东西。

我也在练习把过程写下来。笔记会记录我怎样理解一个概念，项目页会记录我为什么这样做、遇到了什么限制、下一步怎么改。这样朋友可以看到我最近在折腾什么，其他访客也可以从公开内容里看到我的技术兴趣、学习速度和表达能力。
