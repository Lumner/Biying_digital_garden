# 关于我

我是 **浙江大学25级人工智能专业本科生**。这里是我的公开数字花园：放一些学习记录、项目过程、近期状态，也放一个名叫碧影的数字分身，方便访客用对话的方式进入这些公开内容。

我不太想把它做成一份很硬的个人介绍。更希望它像一个还在生长的房间：能看到我在学什么、做什么，也能看到一点日常的判断、兴趣和温度。

## 我的工作方式

我喜欢先把一个想法做出来，再在真实使用中发现问题。对我来说，代码不只是完成作业或通过测试的工具，它也可以是一种表达方式：把模糊的兴趣变成页面、工具、智能体和可交互系统，最后变成别人能打开、能体验、能反馈的东西。

我也想把过程写得更诚实一点。笔记不只放结论，也放理解路径；项目页不只列技术栈，也记录为什么这样做、遇到了什么限制、下一步想怎么改。
