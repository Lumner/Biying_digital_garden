# 碧影数字花园

碧影数字花园是一个用于长期展示个人公开内容的站点。它不是一次性作品集，而是一个会随着笔记、项目和状态页一起增长的空间。

## 技术栈

- MkDocs Material：内容站点和主题系统。
- MathJax：Markdown 数学公式渲染。
- EdgeOne Pages：低成本部署。
- EdgeOne Functions：碧影聊天和公开留言 API。
- EdgeOne KV：留言与轻量数据存储。

## 当前完成

- 双语目录结构。
- 赛博视觉主题。
- 碧影聊天前端。
- 公开留言前端。
- 公开知识库构建脚本。
- EdgeOne API 雏形。

## 设计约束

碧影只能读取公开网页内容。这个约束会写进 persona、知识库构建脚本和 API prompt 中。
