# 个人网页 + 数字分身搭建

这个项目是我为自己搭建的个人数字网站。它既用于记录课程笔记与项目经历，也用于展示我当前正在学习和探索的内容。网站里接入了男性虚构数字分身「碧影」，访客可以通过对话了解公开页面中的内容。

## 背景

我希望有一个更长期、也更有生活气息的空间，用来沉淀学习过程、课程笔记、项目经历和阶段性想法。对朋友来说，它可以回答“你最近在做什么”；对其他访客来说，它可以展示我的技术兴趣、表达能力和持续构建的习惯。

同时，我也想把 AI 协作真正放进一个可访问的作品里，而不是只停留在本地 demo。数字分身「碧影」就是这个实验的一部分：他只读取网站公开内容，用类似 RAG 的方式回答问题，也可以在安全边界内和访客闲聊。

## 我做了什么

- 搭建了 MkDocs Material 项目结构，规划首页、关于、现在、笔记、项目、碧影和留言等页面。
- 设计了 `/zh/` 与 `/en/` 双语内容结构，并实现了整站语言切换，不让中英文导航同时挤在侧边栏里。
- 导入并整理课程笔记，包括离散数学、计算机系统基础和 FDS 数据结构基础。
- 修复课程笔记中的公式渲染问题，把原本被反引号包住的 LaTeX 公式恢复为 MathJax 可渲染格式。
- 为长篇课程笔记整理标题层级，让章节目录出现在右侧侧边栏，方便快速定位。
- 编写 `build_knowledge.py`，把公开页面整理成碧影可读取的公开知识库。
- 设计男性虚构数字分身「碧影」的人格设定，明确他的语气、资料范围和安全边界。
- 编写聊天 API 雏形，让碧影可以基于公开上下文回答问题，并预留 DeepSeek/OpenAI 兼容模型接口。
- 实现公开留言板前端和 EdgeOne KV 风格的留言 API 雏形。
- 编写部署说明和多 Agent 协作说明，方便后续继续扩展。

## 成果

- 网站已经可以本地构建和预览，`mkdocs build --strict` 可以通过。
- 已经形成双语个人网站骨架，包含个人介绍、当前状态、项目展示、课程笔记和数字分身入口。
- 三篇课程笔记已经被整理为网站页面，并支持数学公式渲染和右侧章节目录。
- 碧影可以读取公开知识库，回答网站公开内容相关问题。
- 留言系统和 EdgeOne 部署路线已经具备基础实现。
- 项目结构便于继续添加新的笔记、项目和中英文页面。

## 不足

- 英文笔记目前部分仍是 companion/overview 版本，后续需要接入翻译 API 或人工校对，生成更完整的英文内容。
- 碧影的后端还需要在真实 EdgeOne 环境中配置模型密钥、KV 和限流策略后才能完整上线。
- 留言系统需要进一步加入更完善的审核、删除、反垃圾和管理界面。
- 视觉风格已经有赛博方向，但还可以继续优化移动端细节、可读性和动效。
- 当前项目内容仍处在早期阶段，需要持续补充真实项目经历、学习总结和个人表达。

## 下一步

- 部署到 EdgeOne Pages，并完成 Functions、KV 和环境变量配置。
- 为更多真实项目新增项目页。
- 建立更稳定的中英文翻译工作流。
- 优化碧影的检索质量、来源引用和拒答策略。
- 继续打磨网站视觉，让它既有赛博数字分身气质，也保持舒适的阅读体验。
