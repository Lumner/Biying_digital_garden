# 现在

<span class="status-pill">更新：2026-05-13</span>

这页用来回答“我最近在做什么”。它不追求完整履历，而是保留一个更接近实时的状态切片：学习、项目、生活感和一些正在形成中的方向。

## 正在推进

- 搭建这个基于 MkDocs 的双语个人数字网站，让它成为公开笔记、项目展示、留言和数字分身的入口。
- 设计虚构数字分身「碧影」，让访客可以通过对话了解我公开发布的内容。
- 整理适合长期更新的笔记结构，让中文内容可以稳定翻译成英文，并支持数学公式。
- 练习用 AI 协作完成更完整的作品，而不是只停留在一次性 demo。

## 生活里的状态

最近的我在努力把学习、项目和生活放进同一个节奏里：一边补专业基础，一边做能被真实打开的网站和工具。这个网站也会保留一些不那么“模板化”的东西，比如阶段性的想法、踩坑记录、读到的好内容，以及一些能体现日常温度的笔记。

## 暂不做

- 不让碧影读取未公开的 GitHub 活动、本地文件、草稿或私人记录。
- 不把这个网站做成单一用途的展示页；我更希望它自然呈现专业能力和生活气息。
- 不追求一次性做完。这个站点会随着我的学习、项目和表达慢慢更新。
