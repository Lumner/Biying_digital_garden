# Biying Digital Garden

Biying Digital Garden is a long-term home for public personal content. It is not a one-time portfolio, but a space that grows with notes, projects, and status updates.

## Stack

- MkDocs Material: content site and theme system.
- MathJax: math rendering inside Markdown.
- EdgeOne Pages: low-cost deployment.
- EdgeOne Functions: Biying chat and public guestbook APIs.
- EdgeOne KV: lightweight storage for messages and data.

## Completed

- Bilingual directory structure.
- Cyber visual theme.
- Biying chat frontend.
- Public guestbook frontend.
- Public knowledge builder.
- EdgeOne API skeleton.

## Constraint

Biying can only read public web content. This constraint appears in the persona, knowledge builder, and API prompt.
